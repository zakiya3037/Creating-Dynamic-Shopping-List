# Dynamic Shopping List

## About
A simple and interactive shopping list application built using HTML, CSS, and JavaScript. Users can add shopping items to a list and delete them when they are no longer needed.

## Features
- Add new shopping items.
- Delete individual items.
- Clear the input field after adding an item.
- Prevent empty items from being added.
- Responsive design for different screen sizes.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Open `index.html` in your browser.
2. Enter a shopping item in the input field.
3. Click **Add item** to add it to the list.
4. Click **Delete** to remove an item.

## Concepts Practiced
- DOM manipulation
- `document.createElement()`
- `document.createTextNode()`
- `appendChild()`
- `addEventListener()`
- `textContent`
- `preventDefault()`
- Removing HTML elements with `remove()`

## Project Goal
This project was created to practise JavaScript DOM manipulation and event handling by building an interactive webpage.
